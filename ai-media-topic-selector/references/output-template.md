# Output Template

Save as:

`mymind/creative/01-内容生产/选题管理/ai_topic_YYYY-MM-DD.md`

Use this structure exactly.

Tone requirements for all prose fields:

- Avoid templated contrast phrasing such as `不是...但是...`, `应该...而非...`, `在于...而非...`, `更多是...而非...`, `不应是...而应该是...`, `不只是...还有...`, `不只有...还有...`, `不是...而是...`, `不再是...而是...`, `之所以...是因为...`, and `既是...也是...`.
- State the point directly. Use `因为` / `所以` when a causal link is needed.
- The memo may use structured sections, but judgment paragraphs should sound like an editor talking to a colleague, not a generic AI report.
