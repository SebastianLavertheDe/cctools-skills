# Source Compiler Prompt

Read one raw source and compile it into a reusable source note.

Output requirements:

- Keep the output factual and concise.
- Separate facts from interpretation.
- Produce:
  - summary
  - key signals
  - concept candidates
  - entity candidates
  - theme candidates
  - open questions
- Prefer existing canonical concept names instead of inventing near-duplicates.
- If confidence is low, mark the statement as uncertain instead of overstating.
